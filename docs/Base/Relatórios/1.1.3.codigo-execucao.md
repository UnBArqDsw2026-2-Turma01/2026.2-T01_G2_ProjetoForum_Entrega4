## Evidência da Separação em N-Camadas

Os trechos abaixo mostram o encadeamento unidirecional entre as três camadas: `ForumController` depende apenas de `PublicacaoService`, que por sua vez valida as regras de negócio e delega o armazenamento ao `PublicacaoRepository`.

**Apresentação (`src/apresentacao/ForumController.js`):**
```javascript
import { PublicacaoService } from '../negocio/PublicacaoService.js';

export class ForumController {
  #publicacaoService;

  constructor(publicacaoService = new PublicacaoService()) {
    this.#publicacaoService = publicacaoService;
  }

  async publicar(req, res) {
    try {
      const dados = await this.#lerCorpoJson(req);
      const publicacao = this.#publicacaoService.criarPublicacao(
        dados.autor, dados.titulo, dados.corpo, dados.fonte
      );
      this.#enviarJson(res, 201, publicacao);
    } catch (erro) {
      this.#enviarJson(res, 400, { erro: erro.message });
    }
  }
}

```

**Negócio (`src/negocio/PublicacaoService.js`):**

```javascript
export class PublicacaoService {
  #repositorio;

  constructor(repositorio = new PublicacaoRepository()) {
    this.#repositorio = repositorio;
  }

  criarPublicacao(autor, titulo, corpo, fonte = null) {
    // validação dos campos obrigatórios e criação da entidade Publicacao
    const publicacao = new Publicacao({ autor: autorLimpo, titulo: tituloLimpo, corpo: corpoLimpo, fonte: fonteLimpa });
    return this.#repositorio.salvar(publicacao);
  }
}

```

**Persistência (`src/persistencia/PublicacaoRepository.js`):**

```javascript
salvar(publicacao) {
  if (!publicacao.id) {
    publicacao.id = `p${this.#proximoId++}`;
  }
  this.#publicacoes.set(publicacao.id, publicacao);
  this.#sincronizar(); // grava data/publicacoes.json via node:fs
  return publicacao;
}
```

## Manual de Execução

### Pré-requisitos
* **Node.js 18** ou superior (nenhuma instalação de dependências via `npm install` é necessária).

### Como executar
Na raiz do repositório, execute:

```bash
npm start

```

Ou diretamente via Node.js:

```bash
node src/apresentacao/ForumController.js

```

Em seguida, acesse no navegador:

```text
http://localhost:3001

```

### Fluxo de Verificação Manual

1. Preencher **Autor**, **Título**, **Corpo** e **Fonte (opcional)** e enviar o formulário — a publicação é validada, persistida em `data/publicacoes.json` e exibida na listagem.
2. Tentar enviar com campos obrigatórios vazios — o serviço rejeita a operação e a interface exibe o retorno de validação (`HTTP 400`).
3. Recarregar a página ou reiniciar o servidor — as publicações permanecem disponíveis a partir do arquivo JSON persistido.
